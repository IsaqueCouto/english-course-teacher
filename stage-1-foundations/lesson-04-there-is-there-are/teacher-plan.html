Lesson 4 — There is / There are

How to teach this

This student reads and writes simple sentences well but is just starting Stage 1. The whole lesson is built around writing and recognition — the student never speaks. You (the teacher) do all the talking and reading aloud; the student listens and writes. Keep your English slow and clear, and lean on short Portuguese glosses whenever you introduce a new rule.

The core idea is small but powerful: English uses there is / there are the way Portuguese uses há / tem ("há uma mesa" / "tem uma mesa" = "there is a table"). The trap is agreement — Portuguese speakers often forget that English changes the verb for plural (there ARE two chairs, not there is two chairs). Drill that gently and repeatedly.

Teach the prepositions of place with physical reference: point to real objects in the room as you read example sentences, and have the student write what they see. Recognition before production: by the time they write their own room description at the end, they will have met every pattern several times.

Objective

By the end, the student can read and write descriptions of rooms and places using there is / there are and prepositions of place (in, on, under, next to, between, behind, in front of, near).

Target language

  • there is (+ singular) / there are (+ plural)
  • there isn't / there aren't (negatives)
  • Is there…? / Are there…? (questions)
  • a / an / some / any (a chair, an apple; some chairs; not any windows)
  • Prepositions of place: in, on, under, next to, between, behind, in front of, near
  • Room & furniture vocabulary: table, chair, sofa, bed, window, door, kitchen, bathroom, wall, lamp

Flow with timings (~45–50 min)

Warm-up (5 min) Point around the room and read aloud simple statements: "There is a window. There is a door. There are two chairs." The student listens and writes down the objects they hear. This previews both the structure and the vocabulary with zero pressure.

Present (10 min) Walk through the Key language section on the student sheet. Gloss each rule in Portuguese:

  • there is / there are = há / tem
  • there is + singular; there are + plural — stress this with your fingers (one finger = is, many fingers = are).
  • there isn't / there aren't; Is there…? / Are there…?
  • a/an with singular, some/any with plural. Read each example sentence aloud while the student follows the text and points to the matching object in the room.

Practice (18–20 min) Student works through exercises (a)–(d) in writing. Each exercise begins with a solved example — read it aloud first, then let the student continue. Circulate and correct gently. For listening support, read each prompt aloud once; the student writes the answer. Do not ask the student to speak.

Produce — student WRITES (8–10 min) Exercise (e): read the room description aloud once at normal-slow speed while the student reads along, then the student writes answers to the questions. Exercise (f): the student writes 4–5 sentences describing their own room, using the sentence starters provided.

Wrap-up (3–5 min) Collect the writing. Read back two or three of the student's own sentences aloud, confirming the correct ones with a smile and writing a corrected version beside any agreement errors. Preview homework.

Common mistakes & gentle corrections

  • "There is two chairs." → Plural needs are. Write it side by side: is → are two chairs. Gloss: plural = there ARE.
  • "It has a table in the room." (literal from PT tem) → In English we say There is a table. Há/tem → there is/are.
  • "There are a window." → Singular noun needs is and a: There is a window.
  • "There isn't any chair." → With plural use aren't any: There aren't any chairs. With singular: There isn't a chair.
  • "The lamp is on next to the bed." (two prepositions) → Choose one: next to the bed.
  • Spelling: bathroom, between, behind — correct in writing, no spoken drill.

Homework

On the student sheet: finish any unfinished sentences from Practice, complete the homework section (write 5 sentences about the kitchen using there is / there are + a preposition, from the word bank), and bring it to the next session for written feedback.
