English Course — Beginner → English for Work + IELTS

This is a ready-to-teach English course for one learner: a Portuguese speaker who already has the basics (he reads and writes simple sentences) and is preparing to live and work in English, around November 2026. The end goal is the IELTS General Training test (the version used for work and immigration, not academic study). The course is written for a teacher who is fluent in English and Portuguese but has never taught before — every lesson tells you exactly what to do.

How to use this course

Follow these steps in order. Do not skip step 1 or step 2.

  1. Read the teaching basics — 00-start-here/teaching-basics.md. This is how to teach. Read it before anything else.
  2. Run the placement check — 00-start-here/placement-check.md. Do this with the student before Lesson 1, so you know where to start.
  3. Skim the curriculum map — 00-start-here/curriculum-map.md. See the whole journey so each lesson makes sense in context.
  4. Teach Lesson 1 — stage-1-foundations/lesson-01-present-simple-daily-routines/. Open its teacher-plan.md and follow it line by line.
  5. Update the progress tracker — 00-start-here/progress-tracker.md. After each lesson, tick what the student can now do.

How a lesson works

Every lesson lives in its own folder and contains two files:

  • teacher-plan.md — your step-by-step script for running the lesson. This is for you, the teacher.
  • student-sheet.md — what the learner reads, works through, and keeps. This is the take-home material.

The teacher-plan.md is organized into clear sections so you always know what comes next:

  • How to teach this — the method note for this lesson; read it first.
  • Objective — what the student will be able to do by the end.
  • Target language — the exact vocabulary and grammar to teach.
  • Flow with timings — the lesson minute-by-minute: Warm-up → Present → Practice → Produce → Wrap-up.
  • Common mistakes & gentle corrections — what to expect and how to fix it kindly. (Short Portuguese glosses appear inline wherever a new grammar point needs them.)
  • Homework — the small writing/recognition task to assign (then note progress in the tracker).

The plan

The course moves through three stages. Week ranges are a guide for roughly three lessons per week.

  • Stage 1 — Foundations (weeks 1–6): core grammar and vocabulary — present/past/future tense, questions, daily routines, descriptions, and everyday survival topics (housing, transit, shopping, workplace), with the IELTS "drip" starting as light familiarization.
  • Stage 2 — Building (weeks 7–12): opinions, comparisons, paragraph and letter writing, longer reading and listening, with real IELTS-format practice on each skill.
  • Stage 3 — Test sprint (weeks 13–16): focused practice on the IELTS General Training task types — Listening, Reading, and Writing — with timing, full mock tests, and test strategy.

Honest expectations. A realistic outcome is roughly IELTS band 4.5–5.5, depending heavily on how much the student practices between lessons. The course is modular: if you have more time, slow down and add practice; if a stage is too easy, move faster. The stages are a path, not a deadline.

Design rules

  • The student never speaks in the materials. All written and printed content is recognition, reading, listening, and writing only. There is no pronunciation material. This is deliberate: you, the fluent teacher, coach all speaking live, in person, where you can hear and correct in real time. The sheets are for the silent skills the student can do alone.
  • Everything is fact-checked. Vocabulary, grammar explanations, and IELTS information are accurate. If you find an error, fix it — but the content is built to be trustworthy out of the box.

The supporting IELTS references explain the test itself (ielts/ielts-overview.md) and give a dedicated listening / ear-training resource (ielts/accent-listening.md).

The websites

You can turn the whole course into clean, printable web pages. From the project folder, run:

python3 tools/build_site.py

This builds two sites under website/:

  • a Teacher site — everything: teacher plans, student sheets, the start-here guides, and the IELTS references.
  • a Student site — just the student sheets and the progress tracker, so the learner sees only what they need.

It also creates a chooser page at website/index.html where you pick which site to open.

Any page can be saved as a PDF: open it in your browser and print (Cmd+P), then choose "Save as PDF". Whenever you add or change lessons, re-run the script to rebuild the sites.
